# KVKK doküman içerikleri

Politika, prosedür, talimat ve form içerikleri (Word veya PDF) bu klasöre konacak.
Doküman Yönetimi modülü kurulurken bu dosyalar şablona çevrilecek ve firma bilgileri
aşağıdaki yer tutucularla otomatik doldurulacak:

| Yer tutucu | Alan |
|---|---|
| `{{kurum.unvan}}` | Firma ünvanı |
| `{{kurum.adres}}` | Adres |
| `{{kurum.eposta}}` | E-posta |
| `{{kurum.telefon}}` | Telefon |
| `{{kurum.kep}}` | KEP adresi |
| `{{kurum.yetkili}}` | Yetkili ad soyad |

Önerilen klasör düzeni: `politikalar/`, `prosedurler/`, `talimatlar/`, `formlar/`, `sozlesmeler/`.
Hukuki metin sistem tarafından üretilmez; yalnızca buraya sağlanan içerik kullanılır.
